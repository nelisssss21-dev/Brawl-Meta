# Brawl Meta: Чат-бот для пика героев под ранговый режим

## Описание проекта
Это чат-бот, который помогает игрокам Brawl Stars правильно выбирать бойцов для конкретных карт в Ранговом режиме. Бот анализирует текущую карту, режим («Захват кристаллов», «Награда за поимку», «Горячая зона», «Нокаут») и подсказывает, какие герои будут наиболее эффективны, а каких лучше не брать.

## Значимость проекта
Проект решает главную проблему рангового режима — неправильный пик, из-за которого игроки часто проигрывают ещё до начала матча.

1. **Экономия времени:** не нужно пересматривать десятки видео и разборов, искать тир-листы, бот выдаёт ответ с опорой на «актуальную мету» за пару секунд.
2. **Доступность для всех:** работает прямо в браузере, не требует мощного железа.
3. **Повышение ранга:** помогает игрокам выбирать «метовых» героев под конкретную карту, что увеличивает шанс на победу.

## Функционал (6 функций)
1. **Выбор карты и режима:** пользователь вводит название карты (или выбирает из списка), бот определяет режим игры.
